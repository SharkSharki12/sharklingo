# Sharklingo 🦈

Apprends le **vaelrën** depuis le français ou l'espagnol, avec Sharky le requin.

- 22 unités, 85 leçons, 490 phrases (vaelrën · français · español)
- Exercices : images, QCM, paires, phrases à construire, écriture, écoute, phrases à trous
- XP, séries, cœurs, quêtes, coffres, boutique, exploits
- Histoires interactives, dictionnaire de 714 mots, grammaire complète avec conjugueur

Site statique : ouvre `index.html`, ou active GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
